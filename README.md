# ComicCraft - AI Comic Story Creator

ComicCraft is a web application using Gemini for storytelling and Stable Diffusion for panel illustrations.

## Setup
1. `pip install -r requirements.txt`
2. `uvicorn app.main:app --reload`
3. Access at `http://127.0.0.1:8000`
4. Demo Link : https://drive.google.com/file/d/1dkEAKbCoOEJEgGdeoOoejdAoGdjoSMd3/view?usp=sharing
